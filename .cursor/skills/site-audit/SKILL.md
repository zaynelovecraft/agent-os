# Technical Site Audit

## Checklist

1. **Crawl & Indexability** — Verify `robots.txt`, XML `sitemap.xml`, canonical tags, and HTTP status codes.
2. **Semantic HTML & Headings** — Single `<h1>` per route, logical `<h2>`-`<h3>` hierarchy, landmark elements (`<main>`, `<nav>`, `<article>`).
3. **Structured Data (JSON-LD)** — Validate `Organization`, `WebSite`, `Article`, or `SoftwareApplication` schema with zero Rich Results warnings.
4. **Performance & Core Web Vitals** — Check LCP image priority, font preloading, and bundle size regressions.
5. **AI / GEO Readiness** — Clear entity definitions, high-signal tables/lists, and citable facts.
