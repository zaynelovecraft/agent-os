# Research System (Three-Layer Model)

1. **Index (`research/index.md`)** — Single table cataloging every research log by date, topic, and path.
2. **Logs (`research/logs/YYYY-MM-DD-slug.md`)** — Point-in-time raw findings, benchmarks, and notes.
3. **Canonical Docs / Skills** — Permanent playbooks and `.cursor/skills/` distilled from logs.
