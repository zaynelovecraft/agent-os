# Memory — learned rules and preferences

I check this before every task. When corrected, I add a rule here immediately.

## Learned rules

- Keep replies concise by default — answer first, a few lines max. No tables or extra caveats unless asked for detail.
- Prefer `npm run lint` and `npm run build` for validation before claiming a task is finished.
- Do not start local Docker database stacks unless explicitly asked.
- Do not commit `.env`, credentials, or API keys.
- On git repos: leave changes uncommitted unless explicitly asked to commit and push.
